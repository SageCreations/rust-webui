# WebUI Rust Examples

Examples of how to create a WebUI application in Rust.

## Rust Examples

The only requirement to build the examples is a Rust compiler.

- `minimal`: Creates a minimal WebUI application.
- `call_rust_from_js`: Calls Rust from JavaScript.
- `call_js_from_rust`: Calls JavaScript from Rust.
- TODO: `serve_a_folder`: Use WebUI to serve a folder that contains `.html`, `.css`, `.js`, or `.ts` files.
- TODO: `custom_web_server`: Use your preferred web server like NGINX/Apache... with WebUI to serve a folder.
- TODO: `chatgpt_api`: Calls ChatGPT API from Rust.
- TODO: `frameless`: Frameless window example.
- TODO: `public_network_access`: Allows network access to external devices.
- TODO: `react`: React + WebUI example.
- TODO: `virtual_file_system`: Embeds files using a virtual file system.
- TODO: `web_app_multi_client`: Multiple clients example.

---

To build an example, from the base directory you can run `cargo run` with the `--example` option and the argument being the example's name.

```sh
cargo run --example <example_name>
```
